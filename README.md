This is just a personal music player I made for me, learning Javascript right now and I got bored


Choose an option from the dropdown menu and it will play. Make sure to stop what you're playing first or else it will overlap. Press the Lambda sign to pause your music if it's playing. Or press it again to start your music. The volume slider is for volume. Speed slider makes the song faster or slower. LR Balance will make the sound stronger on either side. Press the stop button to completely stop a track and the restart button to start it over.

More music will be added eventually ;)
